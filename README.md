# No Frontier · Hilton Niseko Village landing

Single-page marketing site for the Jan 27 – Feb 3, 2027 Hilton Niseko Village soft-pack trip.

## Open locally

```bash
# From this folder — simplest (file:// friendly):
open index.html
# or
xdg-open index.html

# Or serve locally:
python3 -m http.server 8080
# then visit http://localhost:8080
```

Relative paths only — works via `file://` without a server.
